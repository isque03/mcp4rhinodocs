You will install MCP4Rhino in Rhino 8, confirm the local MCP server is running, connect Claude or Cursor, and ask a question about your open document.

## What you'll need

- Rhino 8 (Windows or macOS)
- [Node.js](https://nodejs.org/) (`npx`) for the usual AI client bridge
- Claude Desktop, Cursor, or another MCP client

## Step 1: Install in Rhino

<Tabs>
  <Tab title="Package Manager">
    <Steps>
      <Step title="Open Package Manager">
        In Rhino, type `PackageManager` in the **command line** and press Enter.
      </Step>
      <Step title="Install MCP4Rhino">
        Search for **MCP4Rhino**, select the package by **Agent Toolkit**, click **Install**, and apply changes.
      </Step>
      <Step title="Restart Rhino">
        Quit and reopen Rhino when prompted. After restart, MCP4Rhino usually auto-starts on Idle.
      </Step>
    </Steps>

    ![MCP4Rhino in Rhino Package Manager](/images/package-manager-mcp4rhino.png)
  </Tab>
  <Tab title="GitHub .yak">
    Download the universal `MCP4Rhino-<version>.yak` from the [latest release](https://github.com/isque03/mcp4rhino/releases).

    ```bash
    # macOS
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install path/to/MCP4Rhino-<version>.yak
    ```

    ```powershell
    # Windows
    & "C:\Program Files\Rhino 8\System\Yak.exe" install path\to\MCP4Rhino-<version>.yak
    ```

    Restart Rhino after install.
  </Tab>
</Tabs>

## Step 2: Confirm the server is running

Open the Status dialog:

- **Windows:** **Tools → MCP4Rhino → Status…**
- **macOS:** top-level **MCP4Rhino → Status…** (not under Tools)

Or type `MCP4RhinoStatus` / `MCP4RhinoStatusUI` in the Rhino command line.

You want **Running** and endpoint `http://127.0.0.1:4010/mcp`. If Stopped, use **Start server** or type `MCP4Rhino`.

<Tip>
  On macOS the menu is a top-level **MCP4Rhino** item in the menu bar. Looking only under **Tools** is a common miss.
</Tip>

## Step 3: Connect your AI assistant

Add an MCP server that runs:

```text
npx mcp-remote http://127.0.0.1:4010/mcp
```

Full Claude Desktop and Cursor steps: [How to connect Claude or Cursor](/guides/connect-claude-cursor).

Restart or reload MCP in the client after saving config.

## Step 4: Try your first request

With Rhino open, a document active, MCP4Rhino running, and the client connected, ask:

> What objects are currently in my Rhino document?

You should get a summary from the active document. Then try a small create or measure request and watch Rhino update.

## What you built

You now have:

- MCP4Rhino installed and listening on port **4010**
- An AI client bridged to `http://127.0.0.1:4010/mcp`
- A verified path from natural language → Rhino tools
