title: "Quickstart"
description: "Install MCP4Rhino, connect an AI assistant, and run your first Rhino prompt."
---

You will install the plugin in Rhino 8, confirm the local MCP server is running, connect Claude or Cursor, and ask a question about the open document.

## Prerequisites

- **Rhino 8** on Windows or macOS
- An MCP-compatible AI assistant (Claude Desktop or Cursor)
- [Node.js](https://nodejs.org/) (`npx`) for the usual `mcp-remote` bridge

## Get started

<Steps>
  <Step title="Install MCP4Rhino">
    In Rhino, type `PackageManager`, search **MCP4Rhino**, install the package by **Agent Toolkit**, apply changes, and restart Rhino when prompted.

    Or download a universal `.yak` from [GitHub Releases](https://github.com/isque03/mcp4rhino/releases) and install it with Yak, then restart Rhino:

    ```bash
    # macOS
    "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install path/to/MCP4Rhino-<version>.yak
    ```

    ```powershell
    # Windows
    & "C:\Program Files\Rhino 8\System\Yak.exe" install path\to\MCP4Rhino-<version>.yak
    ```
  </Step>

  <Step title="Confirm the server is running">
    After restart, MCP4Rhino usually auto-starts on Idle.

    Open **MCP4Rhino → Status…**:
    - **Windows:** under the **Tools** menu
    - **macOS:** top-level **MCP4Rhino** menu (not under Tools)

    Or type `MCP4RhinoStatus` in the Rhino command line. Status should show **Running** on port **4010**.

    If it is Stopped, click **Start server** or run `MCP4Rhino`.
  </Step>

  <Step title="Connect your AI assistant">
    Point the client at `http://127.0.0.1:4010/mcp` (or `http://localhost:4010/mcp`).

    <Tabs>
      <Tab title="Claude Desktop">
        Merge this into your Claude Desktop MCP config, then restart Claude:

        ```json
        {
          "mcpServers": {
            "mcp4rhino": {
              "command": "npx",
              "args": ["mcp-remote", "http://localhost:4010/mcp"]
            }
          }
        }
        ```

        Details: [How to connect Claude Desktop](/howto/connect-claude).
      </Tab>
      <Tab title="Cursor">
        Add an MCP server that runs:

        ```text
        npx mcp-remote http://127.0.0.1:4010/mcp
        ```

        Enable `mcp4rhino` in Cursor MCP settings, then reload MCP or restart Cursor.

        Details: [How to connect Cursor](/howto/connect-cursor).
      </Tab>
    </Tabs>
  </Step>

  <Step title="Try your first prompt">
    With Rhino open and the server Running, ask your assistant:

    > What objects are currently in my Rhino document?

    You should get a summary from the active document. Then try a small create or measure request and watch Rhino update.
  </Step>
</Steps>

## What you built

You now have a local MCP bridge from your AI assistant into Rhino. Next:

- Browse the [MCP tools reference](/reference/mcp-tools)
- Fix connection issues with [How to troubleshoot](/howto/troubleshoot)

Keep Rhino open while the assistant is modeling. If Status shows Stopped, the client cannot reach the document.
