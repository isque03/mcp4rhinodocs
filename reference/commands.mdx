MCP4Rhino registers Rhino commands and a toolbar/menu from `MCP4Rhino.rui` next to the plugin `.rhp`.

## Menu location

| Platform | Where to find **MCP4Rhino** |
|----------|-----------------------------|
| Windows | Under the **Tools** menu |
| macOS | Top-level **MCP4Rhino** menu in the menu bar (not under Tools) |

Typical menu items: **Status…**, **Check for updates…**, **Report issue…**, and related entries wired to the commands below.

## Commands

| Command | What it does |
|---------|----------------|
| `MCP4Rhino` | Start the MCP HTTP server (also used if auto-start was skipped) |
| `MCP4RhinoStop` | Stop the server |
| `MCP4RhinoStatus` | Command-line summary; opens the Status dialog when run interactively (not scripted) |
| `MCP4RhinoStatusUI` | Always opens the Status dialog (used by menu **Status…**; RUI macros are scripted) |
| `MCP4RhinoUpdates` | Open Rhino Package Manager |
| `MCP4RhinoReportIssue` | Open GitHub Issues in the browser |
| `MCP4RhinoReload` | Hot-reload `MCP4Rhino.Tools.dll` and Logic |

Type these in the Rhino **command line**, not Help search.

## Status dialog

The Status dialog shows running/stopped state, endpoint URL, version, autostart flag, and actions such as Start/Stop, Copy endpoint, Updates, Open log, and Report issue.

Use it as the first check when an AI client cannot connect. See [How to troubleshoot](/howto/troubleshoot).
