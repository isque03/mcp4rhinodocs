MCP4Rhino listens for JSON-RPC MCP requests over HTTP on the local machine.

## Endpoint

| Item | Default |
|------|---------|
| URL | `http://127.0.0.1:4010/mcp` |
| Port | **4010** |
| Bind | Loopback (local only) |

Clients typically use `npx mcp-remote http://127.0.0.1:4010/mcp`. Native HTTP MCP to the same URL works when the client supports it.

Open `http://127.0.0.1:4010/` in a browser for a plain OK response when the server is up.

## Environment variables

| Variable | Effect |
|----------|--------|
| `MCP4RHINO_PORT` | Listen port. Default **4010** if unset or invalid. Update the AI client URL when you change this. |
| `MCP4RHINO_AUTOSTART` | Set to `0`, `false`, or `no` to disable Idle auto-start. You must run `MCP4Rhino` (or Start in Status) yourself. |

Set these in the environment that launches Rhino (shell profile, launch agent, or system env on Windows).

## Auto-start

On plugin load, MCP4Rhino schedules an Idle auto-start unless `MCP4RHINO_AUTOSTART` disables it. Confirm with Status after Rhino settles.

## Logs

| OS | Path |
|----|------|
| macOS | `~/Library/Logs/MCP4Rhino/mcp4rhino.log` |
| Windows | `%LOCALAPPDATA%\MCP4Rhino\mcp4rhino.log` |
