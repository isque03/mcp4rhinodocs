title: "How to install from source or a release yak"

---

You will install MCP4Rhino either from a published `.yak` or by building this repository into Rhino’s packages folder.

## Prerequisites

- Rhino 8
- For source builds: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- For AI clients: Node.js (`npx`)

## Install from a GitHub release

1. Download the universal `MCP4Rhino-<version>.yak` from [Releases](https://github.com/isque03/mcp4rhino/releases).

2. Install with Yak:

   <Tabs>
     <Tab title="macOS">
       ```bash
       "/Applications/Rhino 8.app/Contents/Resources/bin/yak" install path/to/MCP4Rhino-<version>.yak
       ```
     </Tab>
     <Tab title="Windows">
       ```powershell
       & "C:\Program Files\Rhino 8\System\Yak.exe" install path\to\MCP4Rhino-<version>.yak
       ```
     </Tab>
   </Tabs>

3. Restart Rhino. Confirm with **MCP4Rhino → Status…** or `MCP4RhinoStatus`.

## Install from this repository

1. Clone and enter the repo:

   ```bash
   git clone https://github.com/isque03/mcp4rhino.git
   cd mcp4rhino
   ```

2. Pack and install:

   <Tabs>
     <Tab title="macOS">
       ```bash
       bash scripts/install-yak.sh
       ```
     </Tab>
     <Tab title="Windows">
       ```powershell
       powershell -ExecutionPolicy Bypass -File scripts/install-yak.ps1
       ```
     </Tab>
   </Tabs>

   Pack only (no install): `bash scripts/pack-yak.sh` or `scripts/pack-yak.ps1`. Override Yak with env `YAK` if needed.

3. Quit and reopen Rhino. Confirm Status shows Running (or start with `MCP4Rhino`).

## Updating from source

| What changed | What to run | Rhino restart? |
|--------------|-------------|----------------|
| Only Tools / Logic | [Hot-reload](/howto/hot-reload) | No |
| Host `.rhp`, commands, Contracts, or unsure | Full `install-yak`, then restart | Yes |
| Docs only | Nothing to install | — |

## Verification

- `MCP4RhinoStatus` / Status dialog shows the expected version
- `tools/list` against `http://127.0.0.1:4010/mcp` succeeds

## Linux note

Rhino 8 has no official Linux desktop. Run Rhino on Windows, install the package there, and point a Linux AI client at `http://<windows-host>:4010/mcp`.
