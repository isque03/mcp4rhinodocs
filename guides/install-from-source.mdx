---
title: "How to install from source"
description: "Build and install MCP4Rhino from the GitHub repository for development"
---

Install MCP4Rhino from a clone of the product repo when you are developing or testing unreleased changes. End users should use [Package Manager or a GitHub release](/quickstart) instead.

## Prerequisites

- Rhino 8
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Node.js (`npx`) for AI clients
- Git

## Steps

1. Clone and enter the repo:

```bash
git clone https://github.com/isque03/mcp4rhino.git
cd mcp4rhino
```

2. Pack and install into Rhino 8 packages:

<Tabs>
  <Tab title="macOS">
    ```bash
    bash scripts/install-yak.sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    powershell -ExecutionPolicy Bypass -File scripts/install-yak.ps1
    ```
  </Tab>
</Tabs>

The script builds Release, writes `dist/MCP4Rhino-<version>.yak` (universal; version from `manifest.yml`), and installs under the Rhino 8 packages folder.

Pack only (no install): `bash scripts/pack-yak.sh` or `scripts/pack-yak.ps1`. Override Yak with env `YAK` if needed.

3. Quit and reopen Rhino.

4. Confirm with **MCP4Rhino → Status…** or `MCP4RhinoStatus`. If auto-start is off, run `MCP4Rhino`.

## Updating from an existing install

Already installed from this clone and pulling new commits?

1. `git pull` (or check out the branch you want).
2. Pick the upgrade path:

| What changed | What to run | Rhino restart? |
|--------------|-------------|----------------|
| Only Tools / Logic | Hot-reload script, then `MCP4RhinoReload` or MCP tool `mcp4rhino_reload` | No |
| Host `.rhp`, new Rhino commands, Contracts, or unsure | Full `install-yak`, then quit and reopen Rhino | Yes |
| Docs / skills only | Nothing to install | — |

Hot-reload:

```bash
# macOS
bash scripts/hot-reload-tools.sh
```

```powershell
# Windows
powershell -ExecutionPolicy Bypass -File scripts/hot-reload-tools.ps1
```

Then in Rhino: `MCP4RhinoReload`. The MCP URL stays `http://127.0.0.1:4010/mcp` unless `MCP4RHINO_PORT` changed.

## Verification

- Status shows **Running**
- Shell `tools/list` returns tools (see [Troubleshooting](/guides/troubleshoot))
- New tool names appear after hot-reload + `MCP4RhinoReload`

Why Tools hot-reload without restarting: [Architecture](/explanation/architecture).
