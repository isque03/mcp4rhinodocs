---
title: "How to connect Claude or Cursor"
description: "Point Claude Desktop or Cursor at the local MCP4Rhino endpoint"
---

Connect an MCP client to MCP4Rhino so the assistant can call Rhino tools. Rhino must be open and the server must be **Running** (see Status) before the client can connect.

## Prerequisites

- MCP4Rhino installed and listening (default `http://127.0.0.1:4010/mcp`)
- [Node.js](https://nodejs.org/) so `npx` can run `mcp-remote`
- Claude Desktop or Cursor

## Claude Desktop

1. Locate your Claude Desktop MCP config (typically under Claude’s application support folder, or `%APPDATA%\Claude` on Windows).
2. Merge this `mcpServers` entry (or start from the plugin repo’s `examples/claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "mcp4rhino": {
      "command": "npx",
      "args": ["mcp-remote", "http://localhost:4010/mcp"]
    }
  }
}
```

3. Restart Claude Desktop.
4. Confirm the `mcp4rhino` server is enabled and tools appear.

## Cursor

1. Open Cursor MCP settings (UI or project MCP config).
2. Add a server that runs:

```text
npx mcp-remote http://127.0.0.1:4010/mcp
```

3. Enable the `mcp4rhino` server.
4. Restart Cursor or reload MCP after saving.

If your client supports native HTTP MCP to that URL, you may use that instead of `mcp-remote`.

## Custom port

If you set `MCP4RHINO_PORT` to something other than `4010`, change the client URL to match:

```text
http://127.0.0.1:<port>/mcp
```

See [Configuration](/reference/configuration).

## Linux client + Windows Rhino

Rhino 8 has no official Linux desktop. Run Rhino on Windows (or a VM), install MCP4Rhino there, and point the Linux client at:

```text
http://<windows-host>:4010/mcp
```

Replace `localhost` / `127.0.0.1` in the MCP config with the reachable Windows host IP.

## Verification

1. In Rhino, Status shows **Running**.
2. In the AI client, `tools/list` (or the tools panel) includes names like `get_document_info`.
3. Ask: “What objects are in my Rhino document?”

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Client cannot connect | Rhino open? Status Running? Restart the AI client after config edits. |
| `npx` / Node errors | Install Node.js; confirm `npx` works in a terminal. |
| Wrong port | Match `MCP4RHINO_PORT` in the client URL. |

More cases: [How to troubleshoot](/guides/troubleshoot).
